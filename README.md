# Concordance 2027

Outil d'aide au vote pour l'élection présidentielle française de 2027. On répond à une série d'affirmations, on classe les sujets qui comptent pour soi, et l'outil calcule la proximité avec chaque candidat.

## Méthode

- Chaque position de candidat est codée de -2 (pas du tout d'accord) à +2 (tout à fait d'accord), avec un lien vers la source et une courte citation.
- Sources primaires uniquement : programmes, sites de campagne, documents de parti, votes à l'Assemblée et au Parlement européen, entretiens rapportés mot pour mot.
- Une position manquante n'est pas comptée. Une position « déduite » (position du parti, vote du groupe) compte pour moitié et est signalée comme telle.
- Une affirmation n'est affichée que si au moins 4 candidats ont une position sourcée.
- Aucune couleur de parti, aucune photo : l'outil ne recommande personne.

## Fichiers

- `index.html` : le site complet, autonome (toutes les données sont incluses).

Ce site n'est affilié à aucun parti ni candidat. Signalez une erreur de codage en ouvrant une *issue*, avec la source.
